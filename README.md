# sClip
*this is a game clipping software written on rust, works on cpu, uses SIMD quantization and parallel processing.*

*average cpu load on 1080p@144 is 9% (tested on ryzen 5 5600). currently hardcoded for 30 sec recordings.*

***req:***
```
  rust
```
